## 基线发现

1. 1280 像素桌面窗口的导航仅有图标；任务页旁仍显示会话列表，且“我的工作”标题出现两次。
2. 手机“我的工作”藏在工具页内；打开任务页后底栏仍高亮“会话”。
3. 六个任务分组在手机上横向滚动，后面的分组无法直接看见。
4. Agent 协作开关、提及按钮和发送按钮与正文争用输入区空间。
5. 会话列表没有筛选；切换模块会丢失草稿，切换会话可能沿用同一输入控件的文本。
6. 工具页将主题、语言和业务入口全部绘制为独立有边框容器，扫描成本偏高。

以上视觉基线对照了现有源码以及 2026-11-24 的原生 Flutter 渲染截图。修改前实际运行：`flutter analyze --no-pub` 无问题；`flutter test --no-pub` 156 项通过。

## 设计选择

沿用现有绿色主色、MF 标识、系统字体与克制的工作工具风格，改进导航结构、信息层级和输入行为。另两个候选是只微调间距、以及整体更换视觉风格：前者无法解决实际操作路径，后者不符合既有产品方向。本轮采用结构与行为优化。

- 桌面采用带文字的主导航；会话列表只在会话工作面占据固定列。
- 手机底栏直接提供会话、我的工作、知识库、工具；选中项反映当前工作面。会话内提供回到列表的入口。
- 会话筛选只查询当前已加载的标题和摘要；无匹配结果时可以清除筛选。
- 草稿按用户、工作区与会话分开，在当前工作台页面内保留，不额外持久化聊天内容。
- 输入框使用完整宽度，提及和协作模式放在下方工具栏；空白文本不可发送；发送中禁止重复提交。
- 任务页只有一个页面标题；手机使用明确的分组选择器，桌面保留可扫描的分组标签。
- 工具页使用分组列表和明确的偏好设置选项。

## 约束与验收

- 保持现有 Riverpod、任务队列和运行审批接口；不新增依赖。
- 中文、英文和明暗主题均可用；交互目标至少 44×44。
- 320、390、820、1280、1600 像素宽度与 1.8 倍文字缩放不得出现布局溢出。
- 会话与工作区切换不能混用草稿；发送失败保留草稿；中文输入法尚在组词时不执行快捷发送。
- 验证导航、筛选、快捷键、重复提交、草稿恢复、已有权限与运行相关前端回归。
- 除单元/组件测试外，检查实际 Flutter 渲染，并在本地应用中验证高频路径。

## 执行与风险

LoopPilot 模式：Lightweight。由一个实现负责人处理同一 Dart 工作台表面，使用测试、渲染与四轴审阅验证；不需要并行实现或跨运行时集成。风险集中在导航状态、草稿归属、焦点、触控尺寸和异步发送，因此增加对应验证。

实施安排：[实施计划](superpowers/plans/2026-11-25-frontend-experience.md)。

## 已完成的体验改进

- 桌面导航增加文字和分组；任务页面使用完整工作面，减少重复标题与会话侧栏干扰。
- 手机底栏直接进入会话、我的工作、知识库和工具；实际打开的模块决定选中状态。任务分组改为明确的选择菜单。
- 会话支持标题与摘要筛选、清除和空结果提示；Ctrl/⌘+K 保留可见搜索入口。
- 消息输入使用完整宽度，提及与团队模式移到工具栏；Enter 换行，Ctrl/⌘+Enter 发送。空白、发送中和输入法组词期间有相应保护。
- 草稿按用户/工作区/会话归属，切换模块或会话后恢复；失败保留草稿；发送完成后能协调重新挂载的输入框。异步会话与工作区结果采用代次保护，保持最新导航和发送状态。
- 配对、切换设备和移除设备失败后恢复可用状态；连接表单在请求期间保持挂载。提交从点击起锁定，控制器拒绝重叠操作。
- WebSocket 解码兼容现有后端的字符串 ERROR 响应，保留结构化断连信息和正常消息载荷，消除已复现的类型转换异常。

## 验证边界

浏览器尺寸控制接口超时，因此手机浏览器检查采用实际 390×640 的同源应用窗口；原生渲染另覆盖 320、390、820、1280、1600 像素等场景。QA iframe 启动时仍记录一条未定位来源的 MutationObserver 错误；同一最终构建的正常入口没有复现该错误，也不再出现实时消息类型转换异常。

启用 Flutter 语义代理后的自动文本输入存在已记录的工具焦点限制；常规可视控件输入和语义按钮/分组选择分别经过实际验证。真实 Android/iOS 键盘、输入法与安全区、屏幕阅读器、完整 AA 对比度测量、所有浏览器/内容组合，以及未改动业务模块的完整流程尚未验证。现有 gen-l10n synthetic-package 提示和安全存储依赖的 Wasm 兼容性提示不属于本轮变更；成功的 JS 构建不代表 Wasm 构建通过。

以上结果记录依赖升级前的 UI 验收。后续依赖迁移、实际 Wasm / Android 构建及 203 项前端回归见 [依赖升级记录](dependency-upgrade.md)。验证结束时改动保留在工作区；用户随后于 2026-11-26 授权按功能提交并推送。演示后端与静态预览服务在验证后停止，独立演示数据库和验收材料保留以便复查。
